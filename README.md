A single one-line out-of-office reply, written by a tiny Node program to
`/output/entry.txt`:

> I am out of the office and out of opinions until Monday — both will be restocked on my return.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

Node 22, standard library only. The program validates the line against the
competition gate (1–160 characters, one line) before writing it as UTF-8
with no trailing newline.
